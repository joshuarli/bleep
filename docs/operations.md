# Operations

## Deploy

Deploy only from a clean, committed tree:

```sh
node scripts/deploy.ts all
node scripts/verify-live.ts --all
```

`scripts/deploy.ts` stamps `BLIP_TARGET=production`, deploys the Worker with the `cf` CLI, and builds and deploys the Vercel project. It refuses a dirty tree. `scripts/verify-live.ts --all` checks anonymous access, the probe contract, caching, CORS, location, and that all four deployed pieces report the same revision.

## Provider allowances

At default settings a 10-minute Compare session sends 3,000 requests to each provider, 6,000 in total. A full 30-second burst sends 600 per destination instead of 150. The endpoints are public and anonymous and have no rate limiter, so other people's traffic also counts.

Allowances checked on 2026-11-23:

- Cloudflare Workers Free: 100,000 requests per day, about 33 default sessions. Static assets are free. Workers Paid includes 10 million per month, then $0.30 per million.
- Vercel Hobby: 1,000,000 function invocations, 4 hours of Active CPU, 360 GB-hours of provisioned memory, and 100 GB of Fast Data Transfer per month. Invocations allow about 333 default sessions.

Live verification sent fewer than 10,000 requests to each provider, within a 20,000-per-provider cap. The [live browser proof](evidence/live/README.md) is generated by `scripts/browser/live.ts`; regenerate it instead of editing it.

The [Repeated live comparison results](evidence/results.md) record the measurements from one machine and network on 2026-11-23, including the unmeasured Vercel Active CPU and how to read it from the project's usage page.
